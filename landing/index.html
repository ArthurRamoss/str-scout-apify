Install in 30 seconds.

Three ways to call STR Scout.

1. As an MCP server (Claude Desktop, Cursor, Cline)

Add to your claude_desktop_config.json:

{
  "mcpServers": {
    "str-scout": {
      "url": "https://ramosss--str-scout.apify.actor/mcp",
      "headers": { "Authorization": "Bearer <YOUR_APIFY_TOKEN>" }
    }
  }
}

Get a free Apify token at apify.com. Tools appear in your client's palette automatically.

2. As a REST API (your backend, any language)

curl -X POST https://ramosss--str-scout.apify.actor/regulations \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"city":"Austin","state":"TX"}'

3. As a one-shot Apify run (click in the Console)

Visit the STR Scout listing, click Start, fill location, results pushed to the run's dataset. Useful for testing or batch market scans.
